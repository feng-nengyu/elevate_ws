# v3.0.0：电梯按键规划优化与完整测试记录

2026-10-01。此版本保存当前源码、运行手册、测试脚本和完整1～19楼合并结果。

## 本轮测试

- 19个楼层均成功并回Ready；6楼首次退回验收失败，采用复测成功结果。
- 29个按压到位间隔全部<3秒；平均2.377秒，最长2.958秒。
- 2、13、19楼各有一个间隔>2.8秒，尚不满足全部≤2.8秒。
- 时间基准为向前推进完成且TCP位置/姿态验收通过、回退之前的单调时钟事件，包含数字到OK。
- 两次运行合并，不补造跨运行间隔；任务成功没有独立按钮触发确认。

## 主要更新

- 靠近/推进/回退联合预规划重试、相邻键有限分支择优、重复数字跳过零位移转移。
- 合格路径足够短时结束额外候选比较，保留碰撞、真实到位和硬件跟踪保护。
- 可选joint4/joint6规划加速度参数；实际值和驱动速度记入日志。
- 缓存轨迹使用零起始时间戳立即执行，避免动作交接延迟造成OLD_HEADER_TIMESTAMP。
- 测试前自动initialize_arm与Ready验收；参数读取超时20秒并标明具体调用。
- 每次规划请求、候选收益、选定关节路径及10Hz实测TCP轨迹记录。
- 退回位置验收7mm，推进6mm，靠近/平移8mm；速度、间隙和其他保护以主手册与源码为准。
